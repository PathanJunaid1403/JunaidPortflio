# Junaid React Portfolio

A modern, responsive portfolio website built with React, Vite, and Ant Design.

## 🚀 Features

- **Hero Section**: Eye-catching introduction with personal branding
- **About**: Personal background and information
- **Skills**: Showcase of technical skills and expertise
- **Experience**: Professional work experience timeline
- **Projects**: Portfolio of completed projects
- **Contact**: Contact information and social links
- **Responsive Design**: Optimized for all device sizes
- **Modern UI**: Clean, professional design using Ant Design components

## 🛠️ Tech Stack

- **Frontend**: React 19
- **Build Tool**: Vite
- **UI Library**: Ant Design
- **Styling**: SCSS/Sass
- **Icons**: Ant Design Icons
- **Linting**: ESLint

## 📋 Prerequisites

Before running this project, make sure you have the following installed:

- Node.js (version 16 or higher)
- npm or yarn package manager

## 🚀 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd junaidreactportfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**

   Navigate to `http://localhost:5173` (or the port shown in your terminal)

## 📜 Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint for code quality checks
